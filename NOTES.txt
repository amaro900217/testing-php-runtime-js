# PHP WASM Runtime - Development Notes

## 📋 Project Overview

**PHP WASM Runtime in the Browser** - Run PHP code directly in the browser using WebAssembly. Provides inline code execution and complete HTTP request cycle simulation with non-blocking startup.

## 🚀 Quick Start

### Installation
```html
<!-- Load the library -->
<script src="php-runtime.js" type="module"></script>

<!-- Configure the PHP Runtime -->
<script type="module">
  await runPHP.init({
    DEBUG: true,
    NUM_WORKERS: 2
    // ...
  });
</script>
```

### Basic Usage
```html
<!-- Execute Inline PHP Code -->
<script>
  const result = await runPHP.inline('<?php echo "Hello from PHP!"; ?>');
  console.log(result);
</script>

<!-- Make an HTTP-Like Request -->
<script>
  const result = await runPHP.request({
      method: "GET",
      query: "/www/index.php?user=test",
      payload: "otheruser=theuser&value=123",
      headers: "Content-Type:application/x-www-form-urlencoded;"
  });
  console.log(result);
</script>
```

## ⚙️ Configuration Reference

| Option | Description | Default |
|--------|-------------|---------|
| DEBUG | Enable detailed logging | `false` |
| NUM_WORKERS | Number of concurrent workers | `2` |
| TIMEOUT_WORKER | Timeout for each worker (ms) | `1000` |
| DOCUMENT_ROOT | PHP document root | `/www` |
| ENTRY_POINT | Default PHP script | `""` |
| SERVER_ADDR | Virtual server IP | `127.0.0.1` |
| SERVER_NAME | Server name | `browser-localhost` |
| SERVER_PORT | Server port | `8080` |
| SERVER_SOFTWARE | Server version | `wasm-server-0.0.8` |

## 🏗️ Architecture & Workflow

```
[Main Thread: Load Library and Setup Optional Config]
       │
       ▼
[Primary Worker: Install WASM + PHP Project]
       │
       ▼
[Check installation and Initialize Warm up Worker]
       │
       ▼
[Worker Pool: Load WASM, Ready for Requests] ◄─────────────────┐
       │                                                       │
       ├────────────► [runPHP.inline(code)]                    │
       │                      │                                │
       │                      ▼                                │
       │              [Assign Inline Code to Worker]           │
       │                      │                                │
       │                      ▼                                │
       │              [Worker Execution]                       │
       │                      │                                │
       │                      ├─ Run PHP Code in WASM          │
       │                      └─ Capture Output                │
       │                      │                                │
       │                      ▼                                │
       │              *[Return Result to Main Thread]* ───────►│
       ▼                                                       │
[runPHP.request({method, query, payload, headers})]            │
       │                                                       │
       ▼                                                       │
[Request Queue → Assign to Available Worker]                   │
       │                                                       │
       ▼                                                       │
[Worker Execution]                                             │
       │                                                       │
       ├─ Build PHP Environment (Server + GET/POST + Headers)  │
       ├─ Run PHP Code in WASM                                 │
       └─ Capture Output                                       │
       │                                                       │
       ▼                                                       │
*[Return Result to Main Thread]* ──────────────────────────────┘
```

## 🎯 Core Features

- **Server-less PHP Execution**: Run PHP apps without backend
- **Non-Blocking Initialization**: Background worker setup
- **Concurrent Request Handling**: Multiple Web Workers for parallel processing
- **Persistent Caching**: WASM binary and filesystem cached in IndexedDB
- **Full HTTP Environment Simulation**: `$_SERVER`, `$_GET`, `$_POST` superglobals
- **Secure Sandboxing**: Complete isolation from host system

### 🔧 PhpWeb 0.0.8 API Reference

#### Lifecycle API
| Method | Description |
|--------|-------------|
| `new PhpWeb(opts?)` | Constructor |
| `async run(code?, args?)` | Execute PHP string or file |
| `async exec(file, args?)` | Run specific file in VFS |
| `refresh()` | Reboot runtime (keeps persistent VFS) |

#### Convenience Wrappers (Sync)
| Method | Description |
|--------|-------------|
| `r(code): string` | One-liner `run()` wrapper |
| `x(file, args?): string` | One-liner `exec()` wrapper |

#### File System API
| Method | Description |
|--------|-------------|
| `analyzePath(path)` → `FSNode` | Analyze path |
| `stat(path)` → `Stats` | File stats |
| `readFile(path, opts?)` → `string | Uint8Array` | Read file |
| `writeFile(path, data, opts?)` | Write file |
| `mkdir(path)` | Create directory |
| `unlink(path)` | Delete file |
| `rename(old, new)` | Rename file |
| `readdir(path)` → `string[]` | Read directory |
| `php.fs.*` | Raw FS access |

#### Runtime Management
| Method | Description |
|--------|-------------|
| `async loadExtension(url)` | Load `.so` shared library |
| `addSharedLib(name, url, ini?)` | Register shared library |

#### Static Properties
| Property | Description |
|----------|-------------|
| `PhpWeb.phpVersion: string` | e.g. `"8.3"` |
| `PhpWeb.module: EmscriptenModule` | Low-level runtime handle |

### ⚠️ Important Notes
- Auto-transaction mode is always ON (no manual `startTransaction`/`commitTransaction`)
- Version 0.0.8 is Web-only, not CGI-compatible
- For debugging: Enable `ASSERTIONS: 1`, `SAFE_HEAP: 1`, `STACK_OVERFLOW_CHECK: 1`

```javascript
const validateRequest = ({ method, query, payload, headers }) => {
```

#### 4. Memory Management
```javascript
class MemoryMonitor {
  constructor(limitMB = 512) {
    this.limitBytes = limitMB * 1024 * 1024;
    this.usage = new Map();

    if (memory > this.limitBytes) {
      throw new Error(`Worker ${workerId} exceeded memory limit`);
    }
  }
}
```

## 🔒 Security Considerations

### Input Sanitization
```javascript
const sanitizeInput = (input) => {
  return input
    .replace(/[<>]/g, '')
    .replace(/javascript:/gi, '')
    .replace(/on\w+=/gi, '')
    .trim();
};
```

### File System Security
```javascript
const securePath = (path) => {
  if (path.includes('..') || path.includes('~')) {
    throw new Error('Path traversal detected');
  }
  if (!path.startsWith('/www/')) {
    throw new Error('Access outside document root not allowed');
  }
  return path;
};
```

2. **Large File Handling**: No streaming support for large files
3. **Extension Compatibility**: Some PHP extensions may not work
4. **Browser Compatibility**: Limited support in older browsers
5. **Debugging**: Limited debugging in worker context
